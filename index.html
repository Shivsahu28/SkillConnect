Project blueprint

How this idea grows into a full final-year project.

Core roles

Learner, Tutor, Admin. The platform is the trusted mediator between them.

Key modules

Auth, tutor profiles and verification, search and filters, booking calendar, payments, chat and video, reviews, admin panel.

Suggested stack

React or Next.js frontend, Node.js backend, PostgreSQL or MongoDB, Razorpay (UPI, cards, net banking), WebRTC or Jitsi for video.

FAQ

Is this only for school subjects?

No. Any skill that someone can teach well fits: languages, music, coding, cooking, fitness and more.

How does the platform earn money?

A small commission on each completed session, with optional paid promotion for tutors.

How is quality ensured?

Tutor verification, ratings after every class, and a dispute process handled by admins.
